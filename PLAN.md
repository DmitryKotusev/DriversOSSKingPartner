# Автоматизация еженедельного расчёта выплат водителям

Источник требований: [WeekSalaryFillupRoutine.docx](WeekSalaryFillupRoutine.docx).
Дата исследования: 2026-10-02.

## 1. Скоуп (что делает жена каждый понедельник)

Нужно собрать заработок каждого водителя за прошедшую неделю с трёх платформ и свести всё в одну Excel-таблицу.

| Источник | Портал | Период | Колонка с именем | Сумма водителя |
|---|---|---|---|---|
| Uber | fleethub.uber.com → Earnings | «период расчёта» Uber: пн ~04:00 → пн ~04:00 (появляется в пн около 4 утра) | «Ім'я водія» | «Чистий дохід» |
| FREE NOW | portal.free-now.com → Earnings | пн–вс (календарные дни) | «Водій» | «Замовлення від Freenow» |
| Bolt | fleets.bolt.eu → Finanse → Zarobki na kierowcę | «Ostatni tydzień» (пн–вс) | «Kierowca» | «Zarobki netto» − «Pobrana gotówka» |

### Итоговая таблица (Excel)

| # | Колонка | Откуда |
|---|---|---|
| 1 | Водитель | ключ объединения |
| 2 | Uber | API/CSV Uber |
| 3 | Freenow | API/CSV FREE NOW |
| 4 | Bolt | API/CSV Bolt |
| 5 | Партнёрский сбор | конфиг: дефолт (сейчас 230) + исключения по водителям; нет конфига → 0 |
| 6 | Аренда автомобиля | конфиг: аренда по водителям; нет записи/конфига → 0 |
| 7 | Бонус | 0, правится вручную |
| 8 | ZUS | 0, правится вручную |
| 9 | Долг | 0, правится вручную |
| 10 | Терминал | 0, правится вручную |
| 11 | Итоговая выплата | `2 + 3 + 4 + 7 + 10 − 5 − 6 − 8 − 9` |

Все суммы в PLN с точностью до гроша (2 знака после запятой). В коде храним их в грошах как целые числа (`int64`), чтобы не было ошибок округления float. Если какой-то источник отдаст не PLN, программа выдаёт ошибку.

Выходной файл: `Report_<начало>_<конец>.xlsx`, например `Report_2026-09-21_2026-09-27.xlsx`. По умолчанию сохраняется в текущую папку, другую можно задать флагом `--out`. Все имена файлов и папок проекта пишем по-английски.

Кроме основного листа `Report`, в файле будут листы `Uber`, `Freenow`, `Bolt` с исходными данными каждого источника, как они были скачаны (для Bolt ещё `Zarobki netto`, `Pobrana gotówka` и итог по каждому водителю). Они нужны для сверки и отладки; если окажутся лишними, уберём.

Колонку 11 пишем **формулой Excel**, а не числом: тогда после ручной правки колонок 7–10 итог пересчитается сам.

### Правила объединения
- Ключ: имя + фамилия. Сравниваем без учёта регистра, с обрезанными пробелами и схлопнутыми повторными пробелами.
- Если одно имя встречается дважды внутри одного источника, выводим предупреждение (суммы при этом складываем).
- Считаем, что в разных источниках имена совпадают полностью, отличаться может только регистр. Если на реальных данных окажется не так, добавим алиасы.
- Водитель, у которого нет записи в каком-то источнике, получает 0 в этой колонке.
- Отрицательные суммы переносим как есть (подтверждено для Bolt: например −15,25, если наличных забрано больше заработка, и −6,77 еженедельного сбора без поездок). Такой водитель попадает в отчёт.
- Строки, где сумма ровно 0 (старые, неактивные водители), пропускаем. Например, в FREE NOW 118 строк, но с деньгами только 12. Водитель попадает в отчёт, если хотя бы в одном источнике у него ненулевая сумма.
- Предупреждение о дублях выводим, только если повторяющееся имя встречается с ненулевой суммой.

## 2. Как получать данные: результаты исследования

Проверено на реальных данных за неделю 21–27.09.2026 (2026-10-03). Итог: **FREE NOW** — API подтверждён, совпадение до гроша; **Bolt** — официальный API не годится (нет бонусов кампаний), рабочий путь — CSV или внутренний API портала; **Uber** — CSV, запрос на API отправлен.

### 2.1 FREE NOW: внутренний API портала ✅ проверено

Официального API нет, используем тот же backend, что и портал `portal.free-now.com`.

- **Хост API:** `https://api.live.mytaxi.com`
- **Логин:** `POST /partnerauthenticationservice/oauth/token`
  - `Content-Type: application/x-www-form-urlencoded`
  - `Authorization: Basic <client>`: публичный client портала `fnportal-company:<пароль>`, зашит в JS-бандл портала (`/assets/index-*.js`, переменная вида `qy={password:"…",username:"fnportal-company"}`). Программа может доставать его из бандла автоматически при запуске.
  - тело: `grant_type=password&username=<логин>&password=<пароль>&remember_me=true`
  - **Проверено:** вход по логину/паролю работает, без капчи и 2FA. В JWT: `user_id` (это и есть `companyId`), `user_type=COMPANY`, `user_time_zone=Europe/Warsaw`, `user_country_code=PL`.
  - обновление: `grant_type=refresh_token&refresh_token=…`
- **Заработок водителей:**
  `GET /partnermanagementgateway/proxy/partnerbffservice/v2/companies/{user_id}/drivers/earnings?startDate=2026-09-21T00:00:00.000Z&endDate=2026-09-27T23:59:59.999Z&page=0&pageSize=100`
  (даты — локальные дни Варшавы, записанные с суффиксом `Z`, как делает портал; пагинация по `metadata.totalPages`).
- **Нужное поле:** `driverEarnings[].driver.name` и
  - `grossValues.totalFreenowEarnings` = «Замовлення від Freenow» **з ПДВ**,
  - `netValues.totalFreenowEarnings` = то же **без ПДВ**.
  Сверка с CSV портала: **114/114 водителей совпали до гроша** в обоих вариантах. **Берём «з ПДВ»** (подтверждено скриншотами портала: жена использует «Доходи з ПДВ» → «Замовлення від Freenow»). В zip это файл `*_with_VAT.csv`.
- В данных есть 4 повторяющихся имени (разные `publicId`, у всех 0 поездок и 0 PLN): предупреждение выводим, на суммы не влияет.
- CSV-запасной вариант: портал отдаёт zip с двумя файлами `earnings_<from>_<to>_with_VAT.csv` / `..._without_VAT.csv`, колонки «Водій», «Замовлення від Freenow», разделитель `,`, точка в дробях.
- **Риск:** API неофициальный и может поменяться без предупреждения → тогда CSV.

### 2.2 Bolt: официальный API не даёт полной суммы ⚠️

**Официальный Fleet Integration API** (ключи: fleets.bolt.eu → Ustawienia → Dane o połączeniach API):
- Токен: `POST https://oidc.bolt.eu/token`, `grant_type=client_credentials`, `scope=fleet-integration:api`, живёт 600 с. **Проверено, работает.** `getCompanies` → `company_id = 77823`.
- `POST …/fleetIntegration/v1/getFleetOrders` `{company_ids, start_ts, end_ts, limit≤1000, offset}` — заказы с `order_price{net_earnings, ride_price, booking_fee, cash_discount, …}`. За неделю ~10 500 заказов.
- Сверка с CSV «Zarobki na kierowcę»:
  - заказ относится к неделе по `payment_confirmed_timestamp` (так совпадает лучше всего);
  - `Σ net_earnings` + «Zarobki z kampanii» − «Inne opłaty» = «Zarobki netto» у 70/73 водителей;
  - `Pobrana gotówka ≈ Σ (ride_price + booking_fee − cash_discount)` по заказам `payment_method=cash`, точно у 54/73, у остальных расхождение в несколько злотых;
  - **главное:** бонусы кампаний («Zarobki z kampanii», за эту неделю **10 630 zł**) и сбор «Inne opłaty» (6,77 zł) в API **отсутствуют**. Без них итог у отдельных водителей расходится до 848 zł. Поэтому официальный API для расчёта выплат **не используем** (максимум — для контроля).

**Что используем вместо него:**
1. **Сейчас (MVP): CSV «Pobierz → Zarobki na kierowcę».** Формат: UTF-8 с BOM, разделитель `,`, точка в дробях. Сумма водителя считается **по формуле жены: «Zarobki netto|ZŁ» − «Pobrana gotówka|ZŁ»** (подтверждено скриншотом портала, 15/15 водителей совпали с CSV). Колонка «Przewidywana wypłata|ZŁ» в файле равна этой разнице у всех 73 водителей — используем её только как контроль: если вдруг разойдётся, выводим предупреждение.
2. **Позже: внутренний API портала `fleets.bolt.eu`.** В бандле портала есть `/fleetOwnerPortal/driverEarnings/getTable`, `…/getCsv`, `…/getSummary`. Вход: `startAuthentication` → одноразовый код (`getOtpForm`/`submitOtpForm`) → `getAccessToken` по refresh-токену. То есть код с почты/телефона нужен только при первом входе и когда протухнет refresh-токен; срок его жизни проверим отдельно.

### 2.3 Uber: официальный Suppliers API есть, но доступ не самообслуживаемый

- Официальный **Vehicle Suppliers API** (`https://api.uber.com`, OAuth client credentials через `https://login.uber.com/oauth/v2/token`):
  - `GET /v1/vehicle-suppliers/orgs` → зашифрованный `org_id`
  - `POST /v1/vehicle-suppliers/suppliers/{org_id}/reports` с `reportType: REPORT_TYPE_PAYMENTS_DRIVER` и фильтром `dateRange` (epoch ms) → асинхронный отчёт → «Get Report By ID» → «Create Report URL» → CSV. Это то же, что кнопка «Створити звіт» в Fleet Hub.
  - `GET /v1/vehicle-suppliers/earners/payments`: только последние 24 часа, **для недели не годится**.
  - Нужные scopes (`solutions.suppliers.reports`, `supplier.partner.payments`) **привилегированные**: их выдаёт Uber по запросу (через поддержку Fleet Hub или менеджера). Сколько ждать и дадут ли маленькому флоту, неизвестно.
- Внутренний API `fleethub.uber.com` (GraphQL/RPC на cookie-сессии) технически возможен. Но логин Uber (`auth.uber.com`) использует капчу и OTP, поэтому полностью автоматический вход плохо реалистичен.
- **Файл Uber (проверено на 21–28.09):** Fleet Hub → «Звіти» → «Створити звіт» → тип **«Платежі (водій)»** → период недели. Файл вида `20260921_20260928_payments_driver_<фирма>.csv`, UTF-8 с BOM, разделитель `,`, точка в дробях.
  - Имя водителя = «Imię kierowcy» + « » + «Nazwisko kierowcy».
  - Сумма = колонка **«Wypłacono Ci»**: совпала с «Чистий дохід» на странице «Дохід» у 20/20 проверенных водителей (корректировки уже включены).
  - Строку **Emina Mukhtarov** (учётка самой фирмы, в неё попадает перевод всех денег на счёт фирмы, например −126 648,63) **пропускаем** — подтверждено женой. Имя пропускаемых учёток держим в конфиге.
- **Практичный план для Uber:**
  1. **Сразу:** импорт CSV-отчёта. Жена жмёт «Завантажити звіт» (или скачивает готовый отчёт из «Звіти»), программа сама находит файл в «Загрузках» и парсит его.
  2. **Параллельно:** запросить у Uber доступ к Suppliers API. Когда дадут, добавим полностью автоматический коннектор.
  3. **Опционально:** браузерная автоматизация (Go: `chromedp`/`playwright-go`) с сохранённым профилем, чтобы вход руками был раз в несколько недель. Решаем после MVP.

## 3. Архитектура (Go, консоль)

```
cmd/weekpay/main.go          — CLI: weekpay [--week 2026-09-21] [--uber-csv f] [--bolt-csv f] [--freenow-csv f] [--out file.xlsx]
internal/model/              — DriverEarning{Name, Amount, Source}, Week{Start, End}
internal/sources/
    source.go                — interface Source { Name() string; Fetch(ctx, Week) ([]DriverEarning, error) }
    freenow/api.go, csv.go
    bolt/csv.go, (позже) portal.go — внутренний API fleets.bolt.eu
    uber/csv.go, (позже) api.go
internal/merge/              — нормализация имён (регистр, пробелы), предупреждения о дубликатах
internal/config/             — чтение секретов и таблицы водителей
internal/report/             — генерация xlsx (github.com/xuri/excelize/v2), формула в колонке 11
```

### Конфигурация
- `secrets.yaml` (в `.gitignore`, как и текущий `Secrets.txt`): логин и пароль FREE NOW, client_id/secret Bolt, позже ключи Uber.
- `drivers.xlsx`: таблица, которую жена может редактировать сама в Excel:

  | Водитель | Партнёрский сбор | Аренда |
  |---|---|---|
  | *(по умолчанию)* | 230 | 0 |
  | Ahmet Kadak | 150 | 600 |
  | Serhii Rybak | | 500 |

  Пустая ячейка означает «взять значение по умолчанию». Если файла нет, сбор и аренда везде 0, как в ТЗ.

### Неделя
По умолчанию берём прошедшую неделю: пн–вс перед датой запуска. FREE NOW и Bolt запрашиваются по календарным дням. Для Uber берётся период, который начинается в этот понедельник около 04:00 (как в выпадающем списке Fleet Hub). Для перерасчёта есть флаг `--week`.
