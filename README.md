# weekpay

Консольная программа: собирает недельный заработок водителей из Uber, FREE NOW и Bolt и строит Excel-отчёт с выплатами. Подробности и планы — в [PLAN.md](PLAN.md).

## Сборка

Нужен Go 1.25+ (если установлена более старая версия, Go сам скачает нужную при первой сборке).

```
go build -o weekpay.exe ./cmd/weekpay
go test ./...
```

## Установка на компьютер

1. Положите `weekpay.exe` в постоянное место, например `C:\weekpay\`. Если у вас уже есть настроенный `drivers.xlsx`, положите его рядом.
2. Один раз выполните:

   ```
   C:\weekpay\weekpay.exe --install
   ```

   Программа создаст:
   - рабочую папку `Документы\Выплаты`: здесь лежат `drivers.xlsx` и готовые отчёты. Другую папку можно задать: `--install --workdir D:\Выплаты`;
   - `weekpay.ini` рядом с exe, где записан путь к рабочей папке (его можно поправить в Блокноте);
   - `drivers.xlsx` в рабочей папке: копию файла, лежавшего рядом с exe или в текущей папке, а если такого нет — шаблон;
   - ярлык «Выплаты водителям» на рабочем столе.

## Еженедельный запуск (двойной клик)

1. Скачайте с порталов файлы за прошедшую неделю. Переименовывать их не нужно, программа сама найдёт их в «Загрузках»:

   | Источник | Где скачать | Имя файла (пример за 21–27.09.2026) |
   |---|---|---|
   | Uber | Fleet Hub → «Звіти» → «Створити звіт» → «Платежі (водій)» | `20260921_20260928_payments_driver_<фирма>.csv` |
   | FREE NOW | portal.free-now.com → Earnings → скачать (zip) | `earnings_2026-09-21_2026-09-27.zip` |
   | Bolt | fleets.bolt.eu → Finanse → Zarobki na kierowcę → «Ostatni tydzień» → Pobierz | `Zarobki na kierowcę-2026W39-<фирма>.csv` |

2. Дважды щёлкните ярлык «Выплаты водителям». Программа:
   - берёт прошедшую неделю (пн–вс);
   - показывает по каждому источнику, найден ли файл; если нет — что и за какие даты скачать (и замечает, если в «Загрузках» лежит файл за другую неделю);
   - сохраняет `Report_<начало>_<конец>.xlsx` в рабочую папку и открывает его в Excel;
   - если отчёт за эту неделю уже есть, спрашивает «Перезаписать? (д/н)»; при «н» открывает существующий (в нём могут быть ручные правки);
   - если отчёт открыт в Excel, просит закрыть его и нажать Enter;
   - в конце ждёт Enter, чтобы окно не закрылось сразу (в том числе при ошибке).

Файлы за другие недели программа пропускает. Если за нужную неделю есть несколько файлов, берётся самый свежий.

## `drivers.xlsx` — таблица водителей

Лежит в рабочей папке, редактируется в Excel. Если её нет, программа создаёт шаблон сама; вручную: `weekpay --init-drivers`.

| Колонка | Смысл |
|---|---|
| Водитель | имя и фамилия; строка `(по умолчанию)` задаёт значения для всех остальных |
| Партнёрский сбор | пусто — взять значение по умолчанию |
| Аренда | пусто — взять значение по умолчанию |
| Не включать | `да` — не показывать в отчёте (например, учётку фирмы в Uber) |
| Другие имена | другие написания имени в источниках, через `;` — строки объединятся |

Если таблица, указанная флагом `--drivers`, не существует, сбор и аренда везде 0, и никто не исключается.

## Запуск из консоли

Из cmd/PowerShell программа работает так же, но не ждёт Enter в конце и не открывает Excel (включить: `--pause`, `--open`). Если отчёт уже есть, она тоже спрашивает «Перезаписать?»; если ответить некому (ввод не с клавиатуры), завершается с ошибкой — тогда нужен `--force`.

| Флаг | Назначение |
|---|---|
| `--week 2026-09-21` | другая неделя (подходит любой её день) |
| `--workdir <папка>` | рабочая папка (по умолчанию из `weekpay.ini`, иначе `Документы\Выплаты`) |
| `--downloads <папка>` | где искать файлы (по умолчанию из `weekpay.ini`, иначе «Загрузки») |
| `--uber-csv`, `--freenow-csv`, `--bolt-csv <файл>` | указать файл явно |
| `--drivers <файл>` | путь к таблице водителей |
| `--out <папка или .xlsx>` | куда сохранить отчёт (по умолчанию рабочая папка) |
| `--force` | перезаписать существующий отчёт без вопроса |
| `--open`, `--pause` | открыть отчёт в Excel / ждать Enter (по умолчанию — только при запуске двойным кликом) |
| `--install` | создать рабочую папку, `weekpay.ini` и ярлык на рабочем столе |
| `--init-drivers` | создать шаблон `drivers.xlsx` |

`weekpay.ini` (рядом с exe, необязательный; относительные пути — от папки exe):

```
workdir = C:\Users\<имя>\Documents\Выплаты
downloads =
```

Пример на тестовых данных (отчёт и `drivers.xlsx` — в текущей папке):

```
.\weekpay.exe --week 2026-09-21 --downloads samples --workdir .
```

## Отчёт

Лист `Report` содержит колонки Водитель, Uber, Freenow, Bolt, Партнёрский сбор, Аренда, Бонус, ZUS, Долг, Терминал, Итоговая выплата. Бонус, ZUS, Долг и Терминал заполняются вручную, а «Итоговая выплата» — это формула, поэтому после правок она пересчитывается сама. На листах `Uber`, `Freenow`, `Bolt` лежат исходные данные для сверки.

Сообщения `ВНИМАНИЕ:` в консоли (дубли имён, расхождения в Bolt) не останавливают работу, но их стоит прочитать.
