# weekpay

Консольная программа: собирает недельный заработок водителей из Uber, FREE NOW и Bolt и строит Excel-отчёт с выплатами. Подробности и планы — в [PLAN.md](PLAN.md).

## Сборка

Нужен Go 1.25+ (если установлена более старая версия, Go сам скачает нужную при первой сборке).

```
go build -o weekpay.exe ./cmd/weekpay
go test ./...
```

## Что нужно для запуска

1. **Файлы за неделю**, скачанные с порталов. Переименовывать их не нужно, программа сама находит их в `%USERPROFILE%\Downloads` по имени:

   | Источник | Где скачать | Имя файла (пример за 21–27.09.2026) |
   |---|---|---|
   | Uber | Fleet Hub → «Звіти» → «Створити звіт» → «Платежі (водій)» | `20260921_20260928_payments_driver_<фирма>.csv` |
   | FREE NOW | portal.free-now.com → Earnings → скачать (zip) | `earnings_2026-09-21_2026-09-27.zip` |
   | Bolt | fleets.bolt.eu → Finanse → Zarobki na kierowcę → «Ostatni tydzień» → Pobierz | `Zarobki na kierowcę-2026W39-<фирма>.csv` |

   Файлы за другие недели программа пропускает. Если за нужную неделю есть несколько файлов, берётся самый свежий.

2. **`drivers.xlsx`** (необязательно) — таблица водителей. Программа ищет её в текущей папке или рядом с `weekpay.exe`. Создать шаблон:

   ```
   .\weekpay.exe --init-drivers
   ```

   | Колонка | Смысл |
   |---|---|
   | Водитель | имя и фамилия; строка `(по умолчанию)` задаёт значения для всех остальных |
   | Партнёрский сбор | пусто — взять значение по умолчанию |
   | Аренда | пусто — взять значение по умолчанию |
   | Не включать | `да` — не показывать в отчёте (например, учётку фирмы в Uber) |
   | Другие имена | другие написания имени в источниках, через `;` — строки объединятся |

   Если файла нет, сбор и аренда везде 0, и никто не исключается.

## Запуск

```
.\weekpay.exe
```

Программа берёт прошедшую неделю (пн–вс) и сохраняет `Report_<начало>_<конец>.xlsx` в текущую папку. Если отчёт уже существует, он не перезаписывается (там могут быть ручные правки). Перезаписать можно флагом `--force`.

| Флаг | Назначение |
|---|---|
| `--week 2026-09-21` | другая неделя (подходит любой её день) |
| `--downloads <папка>` | искать файлы в другой папке |
| `--uber-csv`, `--freenow-csv`, `--bolt-csv <файл>` | указать файл явно |
| `--drivers <файл>` | путь к таблице водителей |
| `--out <папка или .xlsx>` | куда сохранить отчёт |
| `--force` | перезаписать существующий отчёт |

Пример на тестовых данных:

```
.\weekpay.exe --week 2026-09-21 --downloads samples
```

## Отчёт

Лист `Report` содержит колонки Водитель, Uber, Freenow, Bolt, Партнёрский сбор, Аренда, Бонус, ZUS, Долг, Терминал, Итоговая выплата. Бонус, ZUS, Долг и Терминал заполняются вручную, а «Итоговая выплата» — это формула, поэтому после правок она пересчитывается сама. На листах `Uber`, `Freenow`, `Bolt` лежат исходные данные для сверки.

Сообщения `ВНИМАНИЕ:` в консоли (дубли имён, расхождения в Bolt) не останавливают работу, но их стоит прочитать.
